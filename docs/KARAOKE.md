# RE:KG 唱吧（K 歌 MVP）

当前项目版本：`1.3.0`

Windows 安装包：`release/REKG Setup 1.3.0.exe`

## 已实现

- 右侧导航新增「K 歌」歌曲选择页，可直接搜索歌曲。
- 播放条新增「K歌」按钮，用当前歌曲快速进入工作台。
- 通过酷狗「最优伴奏匹配」接口查找伴奏，并自动解析可播放音轨。
- 伴奏、原唱和麦克风使用独立 Web Audio 混音链，不占用日常播放器。
- 支持原唱、伴奏、人声三路音量。
- 跟随伴奏显示逐句歌词。
- 使用 `MediaRecorder` 录制混音，结束后可立即试听和下载。
- 没有匹配到伴奏时可导入本地 MP3、FLAC、WAV、M4A 等文件继续演唱。
- 未登录时若无原唱音源，仍可只播放伴奏录制人声；登录后可尝试获取高音质原唱轨。
- 全部 JavaScript 文件通过语法检查，并使用模拟麦克风在打包后的 Electron 应用中完成 3 秒录音、试听与作品生成测试。

## 智能练唱（1.3.0）

- 实时分析麦克风基频、清晰度、音量与频谱。
- 实时显示音名、人声状态、瞬时表现分和声音驱动的频谱高度/光盘辉光。
- 演唱结束后生成综合分、等级和音准稳定、节奏进入、长音稳定、表现层次四项评分。
- 自动标记薄弱歌词，并给出进入时机、音量、稳定性与强弱层次建议。
- 支持“循环本句”：在当前歌词句附近建立 A-B 循环，适合反复练习副歌或难句。
- 评分摘要自动保存到本机“成长档案”，最多保留 40 次记录。
- 配置兼容 OpenAI 的模型密钥后，调用 `/api/coach` 根据数值指标生成 AI 教练建议；未配置时使用本地规则反馈。

> 当前伴奏接口不保证提供逐音高的参考旋律，因此“音准稳定”衡量的是基频清晰度和稳定度，不等同于与标准旋律逐音比较后的绝对音准。取得 KTV MIDI/音高数据后，可在 `karaoke-score.js` 中加入参考音高误差。

## 使用

1. 首次使用双击 `install.bat` 安装依赖。
2. 启动本地服务：双击 `start.bat`，或分别运行 `api/app.js --platform=lite` 和 `server.js`。
3. 打开 `http://localhost:3001`，进入「K 歌」。
4. 搜索歌曲并点击「开唱」。
5. 等待页面显示「酷狗伴奏」。
6. 戴耳机，点击「开始演唱」并允许麦克风权限。
7. 点击「结束并生成作品」，试听或下载录制结果。

桌面版 Electron 和普通 Chrome / Edge 支持麦克风录音。部分应用内嵌网页或受限 WebView 不提供 `navigator.mediaDevices`，此时需要使用 `start.bat` 启动普通浏览器版本，或运行 Electron 桌面版。

## 录音与隐私

- 麦克风只在点击「开始演唱」后请求，结束录音时立即停止音轨。
- 当前 MVP 的录音只保存在浏览器内存中，不自动上传到服务器。
- 下载由浏览器生成本地文件；刷新页面前应保存需要的录音。
- 麦克风不使用监听回放，避免扬声器产生啸叫；戴耳机能获得更干净的录音。

## 当前边界

这一版已具备单机智能练唱闭环，不包含云端作品库、账号作品发布、点赞评论、合唱和排行榜。

下一阶段建议按以下顺序扩展：

1. 使用 IndexedDB 保存作品列表，避免刷新后丢失。
2. 新增作品上传接口和对象存储。
3. 增加双人异步合唱：主唱轨和和声轨独立保存后在时间线上混音。
4. 增加作品审核、权限、删除与隐私设置。
5. 增加用户主页、点赞、评论和排行榜。
6. 获得参考旋律后增加绝对音准评分，并把特征计算迁移到 Web Worker。

## 主要文件

- `web/js/karaoke.js`：K 歌曲库、伴奏匹配、Web Audio 混音、录音与作品生成。
- `web/js/karaoke-score.js`：基频检测、人声特征、评分、薄弱句分析与成长档案。
- `web/css/karaoke.css`：K 歌工作台与歌曲选择页样式。
- `web/index.html`：K 歌入口及工作台 DOM。
- `web/js/ui.js`：导航、播放条和 K 歌模块初始化。
- `web/js/api.js`：伴奏匹配接口与统一歌曲字段。
- `api/server.js`：酷狗伴奏接口白名单。
- `server.js`：本地 AI 教练接口和指标摘要转发。
